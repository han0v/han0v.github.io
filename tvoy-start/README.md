# «Твой старт» — молодёжная платформа подработок (MVP)

Законные подработки на 1–3 часа, на лето или постоянно для подростков 14–17 лет. Пилот — Уфа.
Проект **Команды МБ («Мастера бизнеса»)**, мастерская «Большой перемены» 2026.

## Что внутри
- **Законный фильтр:** лента показывает только вакансии, разрешённые по возрасту (ст. 63, 92, 94 ТК РФ).
- **3 режима:** «Час» (ГПХ / самозанятость), «Сезон» (срочный ТД), «Постоянно» (ТД, неполный день).
- **GigaChat-проверка вакансий** — демо на правилах, в продукте планируется GigaChat API.
- **Карта Уфы** по районам, анкеты подростков, Старт-команды, рейтинг компаний, цифровая трудовая, кабинет родителя, Старт-академия, тарифы, техподдержка с чат-ботом.
- Светлая и тёмная темы, адаптив под телефон, планшет и компьютер, полноэкранный режим.
- «Живая» активность демо-пользователей.

## Стек
Чистый HTML + CSS + JavaScript: без сборки, без Node и без бэкенда. Данные демо хранятся в `localStorage` браузера; в меню есть кнопка «Сбросить демо-данные».

```
index.html, vacancies.html, map.html, post.html, gigachat.html, ratings.html,
teams.html, profile.html, parents.html, academy.html, business.html, support.html
css/style.css    — все стили, темы и адаптив
js/data.js       — демо-данные (вакансии, компании, команды, боты)
js/app.js        — логика: шапка, меню, подвал, страницы
assets/          — логотип, иконка GigaChat, favicon
```

## Запуск
- **Локально:** открыть `index.html` двойным кликом.
- **GitHub Pages:** загрузить все файлы в корень репозитория → Settings → Pages → Deploy from a branch → `main` / `(root)`. Через 1–2 минуты сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

> MVP-прототип: компании, люди и цифры демонстрационные.
